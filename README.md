# Mooncat — the mountain cat that bats the moon

A mountain-sized ginger cat batting the full moon like a ball of yarn.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Copies `entry.png` into the output directory as `entry.png`.

## Gate limits

- JPEG, 1024x1024
- 356,403 bytes — under the 1 MiB limit
